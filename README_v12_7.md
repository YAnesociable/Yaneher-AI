# v12.7 — редактор правил и обновлённое управление

Вкладка «Управление → Правила сайта» доступна только администратору. Четыре темы: правила Янехера, сообщества, чата и публикации видео. Поддерживаются многострочный текст, предпросмотр и публикация. Пустое поле возвращает стандартный текст. Введённый текст отображается как текст, без выполнения HTML.

## Обновление работающего сайта
1. Выполните db/v12_7_rules.sql в Supabase SQL Editor существующего проекта.
2. Обновите файлы сайта из этого архива обычным способом.
3. Войдите администратором → Управление → Правила сайта.

Для новой установки используйте db/INSTALL_ALL.sql. Не запускайте полную установку вместо отдельной миграции на существующем сайте.

Миграция добавляет два поля и RPC с серверной проверкой is_admin(); существующие правила сохраняются. SQL подготовлен и проверен по коду, но не выполнялся на вашей базе: доступа к ней нет.

Проверено в автономном Chromium: сохранение и перезагрузка, предпросмотр, экранирование HTML, отсутствие вкладки для гостя и пользователя, отказ демонстрационного RPC для этих ролей, ширина 390 и 1440 пикселей. HTML содержит автономную демонстрацию, настоящая серверная проверка применяется после миграции.
